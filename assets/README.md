# Brand assets

The Ranger marks, as used by this project. Apache-2.0 covers the code in this
repository; these images are the project's identity and are here so the docs can
reference them, not as a grant of trademark rights.

| file | what it is | use it for |
|---|---|---|
| `ranger-icon.png` | full lockup — mark, RANGER wordmark, tagline | README headers, title slides, anywhere with room |
| `ranger-lockup.png` | the mark on its dark rounded-square ground | app icons, avatars, favicons, small square slots |
| `ranger-mark.png` | the mark alone, transparent background | overlays on a dark ground — the outline is pale, so it needs one |
| `ranger.ico` | Windows icon, multi-resolution | Windows shortcuts and executables |

`ranger-lockup.png` carries its own dark background, which is why it is the one
to reach for when a page might render in either light or dark theme.
